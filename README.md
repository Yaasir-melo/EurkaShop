# Eureka Shop

## Project layout

- The HTML pages stay in the project root so the existing page links keep working.
- `css/` contains the storefront and admin stylesheets.
- `js/` contains the storefront, Firebase, Vue header, and admin scripts.
- `docs/` contains the admin setup guide and Firestore rules.
- `product-images/` contains the product photos. `RMC.jpg` and `Winter jacket.jpeg` stay in the root because the existing catalog refers to those paths.

## Open the site

Open the project folder with VS Code Live Server and browse to `index.html`. The site uses Firebase and loads Vue and Font Awesome from the internet, so an internet connection is needed for those features.
